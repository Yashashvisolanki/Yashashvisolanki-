# Yashashvi — UI/UX Portfolio

Static site: `index.html`, `style.css`, `script.js`, `assets/photo.jpg`.

## Edit
- Add your LinkedIn / Behance / Email / Figma at the top of `script.js` (`LINKS`).
- Replace `assets/photo.jpg` to change your photo.

## Deploy on GitHub Pages
1. Create a new repo (e.g. `portfolio`) on GitHub and upload all these files to the root.
2. Repo **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. After about a minute your site is live at `https://<username>.github.io/portfolio/`.
   (Name the repo `<username>.github.io` to get `https://<username>.github.io/`.)
